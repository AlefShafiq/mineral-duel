# 矿物对决 · 现实卡牌版（规则与卡表）

> 一款 1v1 的实体矿物对战卡牌游戏。围绕真实矿物学（莫氏硬度）与世界各地的神话武器展开：把手里的**原石**切割成**宝石**，镶嵌到**神话武器**上获得增益，或者直接把矿物打出当作攻击 / 防御。
>
> 本文件为实体制作与游玩指南，已针对线下桌游做了适配。核心数值与原电子版一致，**仅把随机判定改为掷骰**、把不可见的计数改为**指示物/骰子追踪**。

***

## 1. 概览

| 项目   | 说明                                                                                                                                                |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 人数   | 2 人                                                                                                                                               |
| 时长   | 约 15–25 分钟                                                                                                                                        |
| 目标   | 把对手的**主晶**从 30 点打到 0                                                                                                                              |
| 核心循环 | 原石 →（切割）→ 宝石 →（镶嵌）→ 武器增益 / 或直接打出当攻击或防御                                                                                                            |
| 关键概念 | 自由出牌，无动作点；每个动作**每回合有次数上限**（**普通攻击（原石直接打出）/ 宝石直接打出 / 武器攻击合并为一类，合计 1 次**；普通防御 1 次；切割 6 次；装备与镶嵌不限）；矿物**莫氏硬度**决定切割难度与宝石耐久；直接打出的数值 = 硬度÷2 向上取整（⌈硬度/2⌉） |

***

## 2. 配件清单

每位玩家一副 **46 张**牌组（整套共需 **92 张**；若只印一套，见 §12 的拆牌方案）。

**每副牌组的构成（46 张）**

| 类别   | 张数 |
| ---- | -- |
| 矿物原石 | 38 |
| 神话武器 | 8  |

另需通用指示物：

- **骰子**：每人 1 枚 **d10**（切割判定），桌面共用 1–2 枚 d10（随机效果判定）。

- **主晶血量**：纸笔记录，或用 2 枚 d10 组成 00–30（十位 + 个位）。

- **护盾指示物**：约 15 枚小方块（记录护盾）。

- **宝石指示物**：按 §7 的 53 种宝石准备。**推荐用真实的彩色小石子/玻璃珠**（更贴主题）；也可打印宝石 token。

- **每回合次数指示物**：每人 1 组小骰子/硬币，记录本回合各动作剩余次数（攻击 1，防御 1，切割 6）。

- **武器耐久**：把一枚 d10 直接放在武器卡上表示当前耐久，简洁直观。

- **插槽标记**：武器卡上的插槽圆点，用小珠子压住表示已镶嵌。

## 3. 桌面布局

```
        [对手 主晶 30]   [每回合次数]   [牌库]   [对手武器卡 + 耐久骰]
        ┌───────────── 对手 宝石栏（最多 6） ─────────────┐
        │                                                │
        ├────────────────────────────────────────────────┤
                    （中央：抽牌堆 / 弃牌堆）
        ├────────────────────────────────────────────────┤
        │                                                │
        └───────────── 你的 宝石栏（最多 6） ─────────────┘
        [你的 主晶 30]   [每回合次数]   [牌库]   [你的武器卡 + 耐久骰]

        你的手牌（最多 8 张）
```

- 每人场上只有 **1 个武器槽**（同时只能装备 1 把武器）。

- 每人面前一个**宝石栏**，最多放 **6 颗**宝石。

- 手牌上限 **8 张**，回合结束时若超出需弃牌。

***

## 4. 开局与回合流程

**开局**

1. 各自洗牌，抓 **4 张**手牌。
2. 先手玩家在第一个回合开始时再抽 **1 张**（实际起到 5 张）。

**每回合流程**

1. **回合开始**：每回合次数重置（普通防御 1；普通攻击（原石直接打出）/ 宝石打出 / 武器攻击合并 1；切割 6；装备与镶嵌不限）；若有月光石，主晶 +1；**抽 1 张牌**。
2. **行动阶段**：**自由出牌**，只要未超出该动作的每回合次数上限即可执行（详见 §5）。
3. **回合结束**：**抽 2 张牌**；手牌超过 8 张则弃到 8 张；把回合交给对手。

> 牌库抽空时仍要抽牌：每抽 1 张，你的主晶受到**持续递增的反噬伤害**（第 1 次 1 点，第 2 次 2 点……）。

***

## 5. 动作详解（自由出牌 · 每回合次数上限）

| 动作           | 说明                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------ |
| **① 装备武器**   | **不限次**：从手牌打出一张武器卡，放到武器槽。**未装备武器时不能进行武器攻击。**                                               |
| **② 切割原石**   | **每回合 6 次**：选一张原石卡，掷 d10 判定（见 §6）。成功→得到对应宝石放入宝石栏；失败→原石**留在手中**（仍消耗 1 次切割）。宝石栏已满（6 颗）时不能切割。 |
| **③ 原石直接攻击** | **与 ⑥⑦ 合并计数**：无需切割，直接把一张原石卡打出，对对手主晶造成**等于其硬度一半**（向上取整，⌈硬度/2⌉）的伤害，然后弃掉该卡。                   |
| **④ 原石直接防御** | **每回合 1 次**：无需切割，直接把一张原石卡打出，你的主晶获得**等于其硬度一半**（向上取整，⌈硬度/2⌉）的护盾，然后弃掉该卡。                      |
| **⑤ 镶嵌宝石**   | **不限次**：选一颗宝石嵌入武器（占用 1 个插槽），获得该宝石的加成（见 §7）。插槽满则不能再镶嵌。                                      |
| **⑥ 宝石直接打出** | **与 ③⑦ 合并计数**：选一颗宝石直接打出，对对手主晶造成**等于其所属原石硬度一半**（向上取整，⌈硬度/2⌉）的伤害，然后弃掉该宝石。                    |
| **⑦ 武器攻击**   | **③⑥⑦ 合计每回合 1 次**：用已装备的武器攻击对手主晶，伤害 = 武器当前攻击力；武器耐久 **-1**（有特例见 §8）。三者同属「攻击」一类，每回合只能选其一。     |
| **⑧ 回炉**     | **不限次**：弃掉一张**手牌中的武器卡**（不影响已装备的武器），然后**抽 1 张牌**。用于处理多余的武器、过牌找关键牌。                          |

> 草薙剑特例：其武器攻击**不占用**这次「攻击」次数（见 §8），因此可先草薙剑攻击、再用原石 / 宝石补一次攻击。

> 一句话记忆：**自由出牌、没有动作点；普通攻击 / 宝石打出 / 武器攻击合并每回合 1 次，普通防御 1 次，切割 6 次，装备与镶嵌不限；草薙剑武器攻击不占该次数。多余的武器可「回炉」弃掉换 1 张牌。**

## 6. 切割判定（本版核心适配）

**掷 1 枚 d10，点数 ≥ 该矿物的莫氏硬度 → 成功。**

硬度越高越难，且天然形成一张连续的成功阶梯：

| 硬度 | 矿物                   | 成功需掷出 | 成功率   |
| -- | -------------------- | ----- | ----- |
| 1  | 滑石                   | ≥1    | 10/10 |
| 2  | 石墨、石膏、琥珀             | ≥2    | 9/10  |
| 3  | 云母、方解石               | ≥3    | 8/10  |
| 4  | 孔雀石、萤石、蓝铜矿           | ≥4    | 7/10  |
| 5  | 磷灰石、绿松石、青金石          | ≥5    | 6/10  |
| 6  | 黄铁矿、长石、磁铁矿、欧泊        | ≥6    | 5/10  |
| 7  | 石榴石、石英、橄榄石、堇青石、碧玺、锆石 | ≥7    | 4/10  |
| 8  | 绿柱石、尖晶石、托帕石          | ≥8    | 3/10  |
| 9  | 金绿宝石、刚玉              | ≥9    | 2/10  |
| 10 | 金刚石                  | =10   | 1/10  |

- 切割成功后决定得到哪种宝石：掷 1 枚 d10，按 §7 每行标注的 d10 区段判定；该矿物只有一种宝石时必得。

- 失败时该原石**保留在手**，可以下回合再试。

- 萤石使对手下回合切割难度 +2、紫萤石 +3（即需掷出 ≥ 硬度 + 对应值）。

**随机效果的掷骰换算**

- 冰洲石（穿透 50%）：每次武器攻击掷 1d10，≥6 则本次攻击无视对手护盾。

- 托帕石（穿透 40%）：掷 1d10，≥7 则本次攻击无视对手护盾。

## 9. 武器耐久与结算顺序（建议约定）

为避免线下争议，建议统一按以下顺序结算一次武器攻击：

1. 计算攻击力（基础 + 宝石 + 强化 + 特性）；
2. 判定随机效果（愚人金翻倍、冰洲石穿透）；
3. 计算对手减伤（对手武器上的磁石 -1）；
4. 扣除对手主晶（先扣护盾，除非“无视护盾”）；
5. 结算吸血（祖母绿）、雷击（妙尔尼尔）、贯穿（朗基努斯）、自损（村正）；
6. 武器耐久 -1（金刚石镶嵌的武器免疫）。

**多条同类效果的叠加约定（线下简化）**：

- 磁石/祖母绿等“数值”类：**相加**。

- 穿透/双倍/护甲：取**最高**一条，不叠加，避免结算混乱。

***

## 10. 胜负与结束

- 任意一方主晶降到 **0 或以下**，该方落败。

- 牌库耗尽后的反噬伤害同样可能致负。

## 11. 为实体桌游做的优化（相对电子版）

| 电子版           | 现实卡牌版                  | 原因                 |
| ------------- | ---------------------- | ------------------ |
| 切割成功率按百分比随机   | **掷 1d10 ≥ 硬度**        | 无需程序，一掷即知，且天然是递进阶梯 |
| 35–50% 等概率效果  | 掷 d10 阈值（≥6 / ≥7 / ≥8） | 桌面可执行              |
| 萤石“降低成功率 20%” | 对手下回合**切割难度 +2**       | 掷骰模式更直观            |
| 每回合次数自动显示     | 小骰/硬币翻面记录剩余次数          | 随手可追踪              |
| 主晶血量/护盾自动计算   | 纸笔或双 d10 + 指示物         | 免程序                |
| 萤石耗时 2 秒      | **道具化**（小石子/玻璃珠）       | 增强主题沉浸感            |
| 手牌/宝石栏上限自动拦截  | 靠牌架与宝石槽物理限制            | 上限 8 张 / 6 颗       |
| 无额外记录需求       | 武器耐久用放在卡上的 d10         | 一目了然               |

> 设计原则：**保留全部 28 种矿物与 8 把武器的独特设定**，只替换“不可见的随机与计数”，让规则线上线下一一对应，可直接互相参考。

## 12. 打印与制作建议

- **卡牌尺寸**：63 × 88 mm（标准扑克牌尺寸），300g 以上铜版纸或覆膜。

- **张数**：完整双人对战需 **2 副 × 46 = 92 张**。

- **只印一套时**：把 46 张平均分成两摞（各约 23 张），双方各用一摞即可（武器与高阶宝石会分散到两边，需自行调匀）。

- **建议排版**：

  - 矿物卡正面：名称 / 硬度（大号）/ “切割→多种宝石” / “攻击 N · 防御 N” / 效果小字。

## 13. 可选规则 / 变体（按需启用）

- **宽松切割**：掷 d10 ≥ (硬度 − 2)，最低 1。让高阶宝石更容易成型，适合新手局。

- **耐久即生命**：武器耐久归零时，装备者主晶受到 3 点反噬（惩罚滥砍）。

- **共享牌库**：两人共用一副 46 张牌库（更紧凑，但同名牌会互相争夺）。

- **大师模式**：硬度 ≥8 的宝石镶嵌时额外获得 1 点护盾（强化“稀有=强”的主题）。

【胜负】主晶 30 → 0
